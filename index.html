我的工作

// 组合仪表全生命周期 · 八条主线

01

项目交付

独立负责组合仪表全生命周期开发，推动多个车型完成需求冻结、方案评审、样件验证、整车集成与 SOP 量产，并持续推进量产问题闭环与版本优化。

全生命周期SOP问题闭环
02

需求定义

主导 PRD / SRD 编制与评审，完成显示信息、报警策略、指示灯、背光、声音提示及通信接口的功能定义与变更管理。

PRD / SRD变更管理
03

系统匹配

负责仪表与整车控制器的接口匹配，使用 CANoe、PCAN、ZCANPRO 开展 CAN 信号确认、报文分析、功能联调及通信异常定位。

CANoePCANZCANPRO
04

供应商管理

统筹供应商软硬件开发、版本状态、样件、图纸 / BOM 及问题清单，组织技术评审、样件认可与工程变更，保障技术状态一致与项目节点交付。

BOM样件认可工程变更
05

测试验证

独立制定并执行仪表功能测试，覆盖显示交互、报警逻辑、信号异常、掉电恢复、背光及声音提示等场景，完成问题复现、整改跟踪与回归验证。

功能测试回归验证
06

平台化开发

建立共性功能基线、车型差异清单及参数配置机制，实现同一仪表产品跨车型复用，减少重复需求、软件开发及测试工作量。

功能基线参数配置
07

流程建设

主导编制并推动实施《显示系统交互需求管理办法》，统一需求提出、评审、变更、验证及问题关闭流程。

流程规范跨部门协同
08

全职能覆盖

贯通 FO / SO / DRE / 测试四类角色：从功能需求定义、系统接口设计，到零部件实现与功能验证，端到端负责、对结果负责。

FOSODRE测试
